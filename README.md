# aic-sdk - Rust Bindings for ai-coustics SDK

Rust wrapper for the ai-coustics SDK.

> [!NOTE]
> This SDK requires a license key. Generate your key at [developers.ai-coustics.com](https://developers.ai-coustics.com).

This repository is the bindings' release notes and issue tracker.

- Install: `cargo add aic-sdk --features download-lib`, from [crates.io](https://crates.io/crates/aic-sdk).
- API reference: <https://docs.rs/aic-sdk>
- Issues: <https://github.com/ai-coustics/aic-sdk-rs/issues>
- Models: <https://artifacts.ai-coustics.io>
- Product documentation: <https://docs.ai-coustics.com>
